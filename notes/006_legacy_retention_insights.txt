  Evidence: legacy/test/unit/undo-redo-posture.test.js:25

- Trace switch with dirty computable pins is an undoable fit transition.

  Evidence: legacy/test/unit/undo-redo-posture.test.js:127

- Redoing a loaded image restores the authored image-load context, not a later
  pure mode switch.
  Evidence: legacy/test/unit/undo-redo-posture.test.js:145

- Clear-image undo restores image context and redo returns to native Trace.
  Evidence: legacy/test/unit/undo-redo-posture.test.js:160

- New semantic edits clear redo, but pure mode switches do not.
  Evidence: legacy/test/unit/undo-redo-posture.test.js:179

- Opacity changes do not create undo steps and survive placement undo.
  Evidence: legacy/test/unit/interactions.test.js:603

Derived rule:

History should record semantic user edits, not mechanical UI operations. This
is a direct generalization of the undo/redo posture tests above.
