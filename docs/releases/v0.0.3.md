# id-overlay v0.0.3

This release focuses on making overlay interaction more predictable while
editing in OpenStreetMap iD.

## Changes

- Align mode now keeps plain drag and wheel gestures for the map, with the
  overlay following the live map view.
- Overlay-only transforms are now explicit: `Shift` + drag moves the overlay,
  `Ctrl` + wheel scales it, and `Alt` + wheel rotates it.
- `Ctrl` and `Alt` hover states now show scale and rotate cursors immediately,
  including when keyboard focus is inside the embedded iD editor.
- `Ctrl` + drag and `Alt` + drag are intentionally inert, so transform gestures
  are wheel-driven instead of accidental drag operations.
- Opacity is controlled from the panel slider; `Alt` + wheel no longer changes
  opacity.
- The README now documents the current controls, permissions, local install
  path, and release process.

## Install

Download `id-overlay-chrome-0.0.3.zip` from this release, extract it, and load
the extracted folder from `chrome://extensions` with Developer mode enabled.
